## `04 / research`

**Small Object Detection in Aerial Imagery** · IIIT Sri City

Small objects in drone imagery vanish in a detector's coarse feature maps. This work fine-tunes **YOLO11n** on **VisDrone** and adds a high-resolution **P2 (stride-4) detection head** with COCO-pretrained initialization, then tests **SAHI** sliced inference alongside latency and count ablations.

<div align="center">

| mAP50 | Added params | Throughput | Hardware |
|:---:|:---:|:---:|:---:|
| **25.1% → 32.7%**<br/>`+7.6 pts` | **+0.33M**<br/>with P2 head | **200+ FPS** | single<br/>NVIDIA T4 |

</div>
